# Sreenandan P P – Portfolio (React + Vite)

## Run
```
npm install
npm run dev        # opens http://localhost:5173
```

## Build for hosting
```
npm run build      # output in dist/
npm run preview    # test the build locally
```
Upload the `dist` folder to Netlify, Vercel, GitHub Pages or Cloudflare Pages.

## Edit your content
- `src/data.js`  : name text, jobs, projects, skills, links
- `src/App.jsx`  : page layout and components
- `src/styles.css` : all styling and colors (CSS variables at the top)
- `public/Sreenandan_P_P_CV.pdf` : replace with a new CV, keep the same file name
"# Personal-Portfolio"
